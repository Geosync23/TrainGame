# Designer answers from the review pages

Over two weeks (2026-11-01 to 2026-11-14) the designer answered survey and review pages that were published as claude.ai artifacts. Each page saved its answers in its own small database on the old claude.ai account, and those databases do not move with the repository. This folder keeps a copy of every saved answer so nothing is lost when the project changes accounts.

- Each `.json` file here is the stored document exactly as it was read (pretty-printed), with nothing changed. None of the documents held a user id, name or email, so nothing had to be replaced.
- The decisions these answers led to are recorded in `design-doc.md`, section 0 (the D numbers are given below where they apply).
- The answers use short keys (for example `q.walk` or `trains.dwell`) and short choice values (for example `keep`). The wording of each question and of each choice is in the page's source file in `plans/`, where the keys are defined. Where there is no source file, the question wording is given in the notes below.
- The old links open only for the old account; they will not open for the new account.
- Dates are when the answers were last saved (from each document's `savedAt`, in UTC), or, for pages with no answers, the date the page was last updated.
- A `savedAt` is an ISO date string in the two oldest documents and milliseconds since 1970 (UTC) in all the others.
